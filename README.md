# ETF 调仓计算器

桌面浏览器使用的单文件工具，当前版本 v1.3。按目标仓位、统一交易单位、手续费和预留现金计算调仓方案。

## 功能

- 持仓成本、现价、盈亏、当日盈亏与仓位百分比。
- 根据沪深 ETF 代码按需更新名称和行情。
- 按整手、资金和预留金额约束计算买卖数量。
- 买入、卖出分区展示；实际成交方向和股数须与计划匹配才能写回持仓。
- 用户选择本地 JSON 文件保存；浏览器仅记住文件句柄，下次权限有效时自动读取文件。

## 使用

用近期版本的桌面 Chrome 或 Edge 打开 `public/index.html`，或访问部署后的 HTTPS 网站。首次选择已有 JSON，或新建空白组合。浏览器需要重新授权时点击继续打开。

网页不会上传持仓 JSON，也不会向券商下单。行情请求会向腾讯行情接口发送所选 ETF 代码；行情是否实时、是否可用以接口返回及券商数据为准。

成交方向或股数与计划不一致时，请按真实成交记录修正持仓，不要仅为通过核对而填写计划值。工具当前不支持自动记账部分成交。

## 本地运行与发布

无需构建或安装项目依赖。也可以在项目根目录运行：

```sh
python3 -m http.server 8765 --directory public
```

然后打开 `http://localhost:8765`。

Netlify 导入本仓库时：生产分支 `main`，构建命令留空，发布目录 `public`。配置已写入 `netlify.toml`。

`public/index.html` 是可发布的源码。`outputs/` 下原有桌面历史副本不纳入 Git；个人 JSON、截图、环境文件及 Netlify 本地关联信息也不提交。

本地文件页面、localhost、Netlify 正式域名各自拥有独立浏览器存储和文件授权。首次迁移到新网址，需要在该网址重新选择一次 JSON；后续使用固定网址。

## 国内访问

Netlify 默认域名在中国大陆的可达性取决于地区、运营商和当时网络，不能保证稳定。页面访问与腾讯行情请求是两条独立链路，都需要实际验证。自定义域名也不能作为国内稳定可用的保证。国内稳定访问是硬性要求时，应单独评估合适的托管服务。

## 数据格式

沿用 JSON `schemaVersion: 3`。源代码中的浏览器 IndexedDB 仅记录 `FileSystemFileHandle`，不保存持仓副本；清空默认文件记录不会删除用户的 JSON 文件。
