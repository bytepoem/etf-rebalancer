# ETF 调仓计算器

支持电脑和手机浏览器的单文件工具，当前版本 v1.5。按目标仓位、统一交易单位、手续费和预留现金计算调仓方案。

[小红书关注作者](https://xhslink.cn/o/rXpBcBK0Qy) · [爱发电自愿支持开发](https://afdian.com/a/bytepoem)

部署地址：https://bytepoem-etf-rebalancer.netlify.app/

## 功能

- 持仓成本、现价、盈亏、当日盈亏与仓位百分比。
- 根据沪深 ETF 代码按需更新名称和行情。
- 按整手、资金和预留金额约束计算买卖数量。
- 调仓表以颜色和文字突出买入、卖出；在每笔交易内核对实际方向、股数和成交价，方向和股数与计划匹配后才能写回持仓。保持不动的品种默认收起。
- 电脑支持直接保存到指定持仓文件；不支持该能力的浏览器（包括手机）保存到当前浏览器，并支持导入、导出备份。

## 使用

电脑可用 Chrome 或 Edge 打开 `public/index.html`，手机使用 Safari 或 Chrome 访问部署后的 HTTPS 网站。微信等应用内浏览器的文件选择与分享能力由宿主决定；无法导入或导出时，请从系统浏览器打开。

### 手机使用

1. 点击“新建持仓”填写，或“导入持仓文件”读取电脑导出的备份。
2. 点击“保存持仓”，保存到当前浏览器；下次在同一浏览器访问同一网址时自动恢复。
3. 点击“导出备份”，在系统分享菜单中选择保存到文件，或查看浏览器下载列表。

导入后仍需点击“保存持仓”。导出不会替代浏览器内保存，也不能确认用户是否实际保存了下载文件。手机和电脑之间没有自动同步；需要通过备份文件转移。

浏览器保存使用本地存储，清理浏览器数据、使用无痕模式或更换浏览器可能导致无法恢复。重要持仓请定期导出备份。新建持仓会清除本浏览器已保存的组合，不会删除已导出的文件。

### 电脑直接保存文件

1. 第一次使用：点击“新建持仓”，填写现金、品种代码和股数。
2. 点击“保存持仓”，选择电脑上的保存位置，默认文件名为 `我的持仓.json`。无需手动创建或编辑这个文件。
3. 以后继续使用：网站会尝试打开上次的持仓；如需重新选择，点击“打开持仓文件”。浏览器提示时允许访问即可。
4. 需要备份：点击“另存一份”，选择其他文件名或位置。

之前版本保存的持仓文件可以继续使用，无需转换格式。

网页不会上传持仓文件，也不会向券商下单。行情请求会向腾讯行情接口发送所选 ETF 代码；行情是否实时、是否可用以接口返回及券商数据为准。

成交方向或股数与计划不一致时，请按真实成交记录修正持仓，不要仅为通过核对而填写计划值。工具当前不支持自动记账部分成交。

## 本地运行与发布

无需构建或安装项目依赖。也可以在项目根目录运行：

```sh
python3 -m http.server 8765 --directory public
```

然后打开 `http://localhost:8765`。

Netlify 导入本仓库时：生产分支 `main`，构建命令留空，发布目录 `public`。配置已写入 `netlify.toml`。

`public/index.html` 是可发布的源码。`outputs/` 下原有桌面历史副本不纳入 Git；个人 JSON、截图、环境文件及 Netlify 本地关联信息也不提交。

本地文件页面、localhost、Netlify 正式域名各自拥有独立浏览器存储和文件授权。首次迁移到新网址，需要在该网址重新选择或导入一次持仓文件；后续使用固定网址。

## 国内访问

Netlify 默认域名在中国大陆的可达性取决于地区、运营商和当时网络，不能保证稳定。页面访问与腾讯行情请求是两条独立链路，都需要实际验证。自定义域名也不能作为国内稳定可用的保证。国内稳定访问是硬性要求时，应单独评估合适的托管服务。

## 数据格式

沿用 JSON `schemaVersion: 3`，手机和电脑可交换相同格式的备份。支持文件句柄时，IndexedDB 仅记录 `FileSystemFileHandle`；否则，点击保存后将持仓内容写入当前浏览器的 localStorage。两种模式按浏览器能力选择，不会同时自动读取两套记录。清空默认文件记录不会删除用户的持仓文件。
